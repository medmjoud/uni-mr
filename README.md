# Universités de Mauritanie

An independent, sourced guide to universities, schools and institutes in Mauritania, in **French, Arabic and English**. Built with [Astro](https://astro.build) as a fully static site.

## What's inside

- **Three languages**: French at `/`, Arabic (right-to-left) at `/ar/`, English at `/en/`, with `hreflang` alternates and a language switcher on every page.
- **Directory** of public and private institutions with search (Latin and Arabic, accent-insensitive), filters for type, city and field of study, and shareable filtered URLs.
- **Interactive map** of Mauritania drawn from geoBoundaries region data; select a city to filter the list.
- **Institution profiles** with faculties, degrees, admission notes, a Leaflet/OpenStreetMap location map, schema.org JSON-LD and a numbered source list.
- **Admissions guide**, **scholarships** list and **FAQ**.
- **Live statistics**: tertiary enrollment indicators are fetched from the World Bank Open Data API at build time, with a committed snapshot as an offline fallback.
- SEO: sitemap, canonical URLs, Open Graph image generated at build time, `robots.txt`.

## Getting started

Requires Node 22.12+ (see `.nvmrc`).

```bash
nvm use
pnpm install
pnpm dev        # http://localhost:3000 (Astro picks the next free port if taken)
pnpm build      # type-check + static build into dist/
pnpm test       # data integrity tests
```

Set `SITE_URL` in the deploy environment to the production domain so canonical URLs, the sitemap and `robots.txt` point to the right place.

## Data

| File | What it holds |
| --- | --- |
| `src/data/institutions.json` | One entry per institution, validated by the schema in `src/content.config.ts`. Every entry needs at least one source. |
| `src/data/context.json` | Admissions steps, Bac series, scholarships, key figures and FAQ (English), validated in `src/lib/context.ts`. |
| `src/data/i18n/*.json` | French and Arabic versions of the guide content and of each institution's summary, highlights and admission note. |
| `src/i18n/ui.ts`, `src/i18n/terms.ts` | Interface text, plus translations for fields of study, degrees, languages and Arabic city names. |
| `src/data/geo/mauritania.json` | Region outlines, generated by `pnpm geo` from geoBoundaries (CC BY 4.0). |
| `src/data/worldbank-snapshot.json` | Fallback copy of the World Bank indicators. |

When you change a fact, add or update its source, update the French and Arabic text in `src/data/i18n/`, and bump `LAST_VERIFIED` in `src/lib/institutions.ts`. `pnpm test` fails if a translation is missing or out of shape.
